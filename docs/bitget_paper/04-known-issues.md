# 已知问题

- 只有 BTCUSDT 现货。没有股票代币，没有合约，没有做空。
- 卖出一次卖光，没有部分减仓。
- 均线规则没有经过样本外检验，不能当成可交易优势。
- K 线只接受 `1m`。中间缺一根就会停止这一轮，直到序列重新连续。
- 本地时钟和交易所差得太多时，行情会被拒绝。
- 锁是本机文件锁，不能管多台机器。
- 权益曲线在状态里只留最近 120 点。完整追加在 `equity_path`。
- 状态页没有登录。它只应该出现在本机。
- 仓库目前没有 GitHub Actions 检查。测试要在本地跑。
- 公开行情只做过短轮询，没有多日浸泡。
- 开发机上的 `--run` 会在进程结束时停掉。它不是常驻服务。
